# 엑셀 근무표 내려받기

근무표 화면에서 연도와 월을 고른 뒤 **엑셀 내보내기**를 누릅니다.
PDF 버튼도 그대로 사용할 수 있습니다. 서버에서 파일을 생성하므로 HTML 파일을 직접 여는 대신 `npm start`로 실행합니다.
기존 서버를 실행 중이었다면 `npm install` 후 서버를 다시 시작하고 브라우저를 새로고침합니다.

- 제공된 2026년 10월 내부용 샘플의 셀 병합, 결재란, 열 너비, 행 높이, 인쇄 설정을 사용합니다.
- NC: 해당 월에 재직하는 교대근무자를 화면 순서대로 최대 4명 출력합니다. 수동 수정·휴가·대근 등 화면의 실제 근무값을 사용하며 재직 기간 밖의 날짜는 비웁니다. 4명을 넘으면 오류를 표시합니다.
- TC: 직원 설정에서 교대 루틴을 끈 추가 일근자·교육생을 출력합니다. 해당 월의 화면 순서·실제 근무값·재직 기간을 반영합니다. 없으면 행을 생략하고 여러 명이면 인원수만큼 늘립니다. 일근자와 비고, 병합 범위·인쇄 영역도 함께 이동합니다.
- 오른쪽 휴가신청절차와 대일·휴가 표시 안내를 원본 위치에 유지합니다. 원본처럼 오른쪽 안내는 근무표 인쇄 영역 밖에 있습니다.
- 일근: 설정 → 관리자 설정 → **엑셀 일근자 이름**에서 입력하고 설정을 저장합니다. 기본값과 빈칸 입력 시 이름은 서예찬입니다. 저장한 이름은 새로고침 후에도 유지됩니다. 평일은 `일`, 토·일요일과 앱에 등록된 공휴일·회사 휴일은 `O`입니다. 실제 직원 등록이나 교대근무 계산은 바꾸지 않습니다.
- 월의 마지막 날짜 이후 칸은 비우며 주말·휴일 배경과 휴가 색상을 다시 계산합니다.
- 결재란의 이름과 비고는 공란입니다. 샘플에 있던 이전 이름·휴가·대근 메모와 깨진 수식은 복사하지 않습니다. 필요한 비고는 내려받은 엑셀에서 작성할 수 있습니다.

`templates/schedule.xlsx`는 개인정보와 이전 근무값을 지운 배포용 양식입니다. `sample`의 원본은 수정하지 않습니다.
검증: `node --test tests/excel-export.test.js`

다른 PR과 합칠 때 정적 파일 허용 목록을 확대할 필요는 없습니다. `/api/export/excel`은 읽기 전용 파일 생성 API이며 DB나 알림 발송을 호출하지 않습니다.

## 처음 설치하거나 업데이트할 때

1. PR을 반영한 프로젝트에서 `npm install`을 실행합니다. 새 엑셀 처리 라이브러리도 설치됩니다.
2. 기존 서버를 종료하고 `npm start`로 다시 실행합니다. 이름 등 관리자 설정을 바꾸려면 기존 관리자 로그인 설정도 필요합니다.
3. 서버 주소로 접속해 브라우저를 새로고침합니다. 여러 PC가 접속한다면 각 브라우저도 새로고침합니다.
4. 월을 선택하고 다운로드합니다. 파일명은 `2026년 10월 통합관제실 근무표.xlsx` 형식입니다.

개인 PC에만 있는 `sample` 폴더는 필요하지 않습니다. PR에 포함된 **`templates/schedule.xlsx`가 실제 출력 양식**입니다. 배포하거나 프로젝트를 복사할 때 이 파일도 함께 가져가야 합니다.

## 인원과 이름을 관리하는 방법

| 바꾸려는 내용 | 설정할 곳 | 엑셀 반영 방식 |
| --- | --- | --- |
| NC 이름·순서·근무 | 기존 직원 구성과 월별 근무표 | 해당 월에 재직하는 교대 루틴 인원을 화면 순서대로 최대 4명 출력 |
| 신입 교육생·추가 일근자 | 직원 구성에서 인원 추가 후 교대 루틴 해제 | TC에 출력. 직원 등록만으로 평일 일근을 자동 생성하는 기능은 아니며, 화면에 표시된 근무값을 그대로 사용 |
| 별도 일근 행의 이름 | 관리자 설정의 엑셀 일근자 이름 | 기본 서예찬, 최대 50자. 저장 완료 후 다음 다운로드부터 적용 |
| 별도 일근 행의 휴가·개별 근무 | 현재는 전용 설정 없음 | 이름만 설정 가능. 평일 `일`, 주말·앱의 휴일 `O`로 생성 |

별도 일근 행은 직원 명부와 연결되지 않습니다. 같은 사람을 TC 인원으로도 등록하면 두 곳에 출력될 수 있으니 중복 등록 여부를 확인하세요. 저장 오류나 충돌 안내가 뜬 경우 저장을 완료한 뒤 다운로드하세요.

## 양식을 직접 수정할 때

현재 버전은 **이 샘플의 정해진 위치와 서식을 전제로 만든 출력 기능**입니다. 아무 엑셀 파일로 교체해도 작동하는 범용 양식 편집 기능은 아닙니다.

| 수정 내용 | 현재 동작과 필요한 확인 |
| --- | --- |
| 열 너비·행 높이·여백·용지 방향·인쇄 배율 | 기존 셀 위치를 유지하면 반영 대상입니다. 저장 후 다운로드와 인쇄 미리보기로 확인하세요. |
| 글꼴·글자 크기·정렬·테두리 | 일부는 템플릿에서 가져오지만 날짜·근무 칸은 공통 서식으로 다시 만듭니다. 개별 칸에서 바꾼 서식이 그대로 반영된다고 보장하지 않습니다. |
| 주말·휴일·휴가 색상 | 코드가 날짜와 근무값에 따라 다시 지정합니다. 특정 날짜 칸만 칠하는 방식으로 고정할 수 없습니다. |
| 제목·이름·날짜·근무·오른쪽 안내·하단 근무시간 문구 | 코드가 매번 채웁니다. 템플릿에 글자만 고쳐도 덮어쓰며, 고정 문구는 `excel-export.js`도 수정해야 합니다. 방송국명 설정도 현재 엑셀 제목에는 연결되지 않습니다. |
| 비고·결재자 이름·새 문구·수식 | 코드가 채우도록 정한 셀 이외의 값과 수식은 지웁니다. 계속 사용할 문구는 코드에 추가하고, 일회성 메모는 다운로드한 파일에 작성하세요. |
| 행·열 삽입/삭제, 이름·날짜 칸 이동, 셀 병합 변경 | 셀 주소와 TC 행 처리도 함께 수정해야 합니다. 템플릿만 바꾸지 마세요. |
| 시트 추가·삭제·순서 변경, 다른 양식 파일로 교체 | 현재 지원 범위 밖입니다. 출력 코드와 테스트를 함께 맞춰야 합니다. 파일은 `.xlsx` 형식을 유지하세요. |

코드는 `xl/worksheets/sheet1.xml`과 샘플의 일부 서식 번호를 직접 사용합니다. **엑셀 편집기에서 저장하면서 내부 서식 번호가 재구성되면, 셀 위치를 그대로 두어도 서식이 달라지거나 생성에 실패할 수 있습니다.** 글꼴·색상 변경도 실제 출력 검증이 필요합니다.

수정 순서는 다음과 같습니다.

1. `templates/schedule.xlsx` 원본을 별도로 백업합니다.
2. **실제 서버가 실행 중인 프로젝트 폴더**의 파일을 수정하고 저장합니다. 다른 PC나 다른 작업 폴더의 파일을 바꿔도 해당 서버에는 반영되지 않습니다.
3. `node --test tests/excel-export.test.js`를 실행합니다. 코드도 수정했다면 `npm test`도 실행합니다.
4. 2월·윤년 2월·30일·31일인 달과 TC 없음/1명/여러 명인 경우를 내려받습니다. Excel에서 복구 경고가 없는지, 이름·날짜·색상·병합·안내가 맞는지 확인합니다.
5. Excel 인쇄 미리보기에서 잘림, 페이지 수, 글자 크기를 확인합니다. TC 인원이 늘거나 열 너비를 바꾸면 한 장에 맞추는 과정에서 글자가 작아질 수 있습니다. 자동 테스트 통과만으로 모든 편집기·프린터의 모양을 보장하지 않습니다.
6. 문제가 있으면 백업한 템플릿으로 되돌리고 다시 다운로드합니다. 검증한 템플릿과 필요한 코드 변경을 함께 커밋·PR로 공유합니다.

**템플릿 파일만 수정하면 다음 다운로드부터 읽으므로 서버 재시작은 필요 없습니다.** 서버 코드를 바꾸거나 의존성을 추가했다면 서버를 다시 시작해야 합니다. 이미 다운로드한 파일은 바뀌지 않으므로 새로 받아야 합니다.

## 인쇄와 내려받은 파일 편집

- 기본 인쇄 영역은 근무표 본문이며 오른쪽 대일·휴가 안내는 제외됩니다. 안내까지 인쇄하려면 다운로드한 파일에서 인쇄 영역을 넓히고 배율을 확인하세요.
- 내려받은 파일의 이름·근무·비고를 수정해도 웹의 공유 근무표에는 반영되지 않습니다. 엑셀 수정본을 다시 가져오는 기능은 없습니다.
- 다음 다운로드는 화면의 현재 근무값으로 새로 생성합니다. 이전에 엑셀에서 적은 메모나 수정한 값은 이어 붙이지 않습니다.
- 승인 당시 보관본을 골라 내보내는 기능은 없습니다. 제출 전 선택한 월과 현재 승인 상태를 확인하세요.

## 잘 안 될 때

| 증상 | 먼저 확인할 내용 |
| --- | --- |
| 엑셀 버튼이 안 보임 | 서버의 코드가 업데이트됐는지 확인하고 브라우저 새로고침 |
| 다운로드 서버 연결 오류 | HTML 직접 열기인지, 서버가 실행 중인지, 업데이트 후 재시작했는지 확인 |
| 파일 생성 실패 | 서버 로그에서 `엑셀 생성 오류` 확인. `npm install` 누락, 템플릿 파일 누락·손상·구조 변경 여부 확인 |
| NC 인원이 4명을 넘는다는 안내 | 직원의 교대 루틴 여부와 선택한 달의 재직 인원 확인. 추가 일근자·교육생이라면 교대 루틴 해제 |
| 일근자 이름이 예전 이름임 | 관리자 설정 저장 완료 여부, 서버·작업 폴더가 맞는지, 새로 다운로드한 파일인지 확인 |
| 셀이 깨지거나 Excel에서 복구 경고가 뜸 | 원래 템플릿으로 되돌려 재다운로드. 해결되지 않으면 문제 파일, 사용한 Excel/뷰어 이름·버전, 선택한 월, TC 인원수, 경고 문구를 함께 전달 |
